# 🔐 Password Generator

A simple and responsive Password Generator Web Application built using **HTML, CSS, and JavaScript**.

This project allows users to generate random passwords with customizable length and character types, including uppercase letters, lowercase letters, numbers, and symbols.

## ✨ Features

- Generate random passwords instantly.
- Customize password length (1–20 characters).
- Include uppercase letters (A–Z).
- Include lowercase letters (a–z).
- Include numbers (0–9).
- Include special symbols.
- Password strength indicator.
- Copy generated password to clipboard.
- Interactive slider for password length.
- Responsive user interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, layout, and animations.
- **JavaScript** – Password generation and functionality.
- **Clipboard API** – Copy password functionality.

## ⚙️ How to Run Locally

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Password-Generator
```

3. Open `index.html` in your browser.

4. Select your preferred password options.

5. Click on **Generate Password**.

6. Copy your generated password using the copy button.
